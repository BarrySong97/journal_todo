# Agent Instructions (`@journal-todo/website`)

This package is the public website (Next.js) for distribution and release communication.

## What this package does

- Hosts marketing-style pages and app preview.
- Provides download links and release notes pages.
- Embeds the web app preview component in the homepage.

## Primary business responsibilities

- Present product narrative and entry points.
- Render release/download data from JSON artifacts under `app/data`.
- Serve as deploy target for Vercel (Root Directory should be `packages/website`).

## Structure

- `app/layout.tsx`
  - Root layout + metadata.
- `app/page.tsx`
  - Homepage.
- `app/components/HomeEmbeddedApp.tsx`
  - Dynamic embedding wrapper for `@journal-todo/web/AppTSX`.
- `app/downloads/page.tsx`
  - Download page (reads `app/data/downloads.json`).
- `app/release-notes/page.tsx`
  - Release notes page (reads `app/data/release-notes.json`).
- `app/data/*.json`
  - Generated release/download data consumed by pages.
- `next.config.ts`
  - Next config (including static export mode).
- `vercel.json`
  - Package-local Vercel config for website deployment.

## Integration points

- Consumes `@journal-todo/web` (embedded app preview), `@journal-todo/ui`, and `@journal-todo/shared`.
- Receives data artifacts generated by root `release.sh notes`.

## Commands

- Dev: `pnpm -C packages/website dev`
- Build: `pnpm -C packages/website build`
- Typecheck: `pnpm -C packages/website typecheck`

## Change guidelines

- Keep website pages data-driven where possible.
- Do not hardcode release/download metadata if script-generated JSON exists.
- Keep deployment assumptions aligned with `packages/website` root on Vercel.
